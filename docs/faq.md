## 1. 杀毒软件报毒怎么办？

**这是误报，不是病毒。**

SuperMOA 使用 PyInstaller 将 Python 程序打包成单个 .exe 文件。这种打包方式会被部分杀毒软件（如 360、火绒、Windows Defender）误报为"潜在威胁"，但实际上 SuperMOA 是完全安全的开源软件。

### 解决方法

| 杀毒软件 | 处理方法 |
|---------|---------|
| **360 安全卫士** | 设置 → 信任区 → 添加 `SuperMOA.exe` |
| **火绒** | 防护中心 → 信任区 → 添加 `SuperMOA.exe` |
| **Windows Defender** | 设置 → 病毒和威胁防护 → 排除项 → 添加 `SuperMOA.exe` |
| **其他杀毒软件** | 在软件设置中找到"白名单"或"信任区"功能，添加 `SuperMOA.exe` |

### 为什么会被误报？

- PyInstaller 打包的 exe 包含完整的 Python 运行时，体积较大
- 杀毒软件的启发式扫描对"自解压 + 运行"行为敏感
- 这是 PyInstaller 社区的已知问题，不是 SuperMOA 独有

> 📌 你可以放心使用。SuperMOA 是开源软件，所有代码都可以在 [GitHub](https://github.com/SuperMOA/SuperMOA) 上审查。

## 2. Windows SmartScreen 拦截怎么办？

首次运行 `SuperMOA.exe` 时，Windows 可能弹出蓝色 SmartScreen 窗口，提示"已保护你的电脑"。

### 解决方法

1. 在 SmartScreen 窗口中点击「**更多信息**」
2. 点击「**仍要运行**」
3. 之后再次运行就不会再出现提示

### 为什么会这样？

SmartScreen 会拦截"未知的"可执行文件。这是因为 SuperMOA 目前没有购买代码签名证书（证书费用较高）。这**不影响安全性**，只是 Windows 对未签名程序的常规提示。

> 📌 如果你希望未来不再出现此提示，可以将 `SuperMOA.exe` 添加到 Windows 的信任列表中。

## 4. 配置页打不开怎么办？

### 排查步骤

1. **确认 SuperMOA 在运行**
   - 查看系统托盘是否有蓝色 S 图标
   - 如果没有，双击 `SuperMOA.exe` 启动

2. **手动打开**
   - 在浏览器地址栏输入：`http://127.0.0.1:12345/`
   - 注意不要漏掉 `http://`

3. **检查端口是否被占用**
   - 如果 12345 端口被其他程序占用，SuperMOA 可能启动失败
   - 解决：命令行运行 `SuperMOA.exe --port 12346` 换一个端口

4. **检查配置文件**
   - 配置文件位置：`~/.moa-gateway/config.yaml`（即 `C:\Users\你的用户名\.moa-gateway\config.yaml`）
   - 如果文件不存在，SuperMOA 会在首次启动时自动创建
   - 如果文件损坏，可以删除后重启，会重新生成

5. **查看日志**
   - 命令行运行 `python main.py` 可以看到详细日志

## 5. 模型调用失败怎么办？

### 常见原因和解决

| 原因 | 现象 | 解决方法 |
|------|------|---------|
| API Key 错误 | 返回 401 Unauthorized | 检查 Key 是否复制完整，有无空格 |
| 余额不足 | 返回 402/403 | 去厂商官网充值 |
| base_url 错误 | 返回 404 或连接超时 | 对照配置页的厂商预置地址 |
| 网络不通 | 连接超时 | 检查网络、防火墙、代理设置 |
| 模型名错误 | 返回 404 Model not found | 对照厂商文档确认模型名 |

### 排查方法

1. 在配置页点击每个模型旁的 **⚡ 测试** 按钮
2. 根据错误提示定位问题
3. 如果是 `degraded_policy: loud`，错误信息会传给聚合模型处理
4. 如果是 `degraded_policy: silent`，失败的模型会被静默跳过

## 6. 怎么卸载？

SuperMOA 是绿色软件，无需安装程序，卸载很简单：

### 卸载步骤

1. **关闭程序**：右键托盘图标 → 退出
2. **删除 exe**：删除 `SuperMOA.exe` 文件
3. **（可选）删除配置**：删除 `~/.moa-gateway/` 目录

### 配置文件位置

```
C:\Users\你的用户名\.moa-gateway\
├── config.yaml         # 配置文件
├── .api_key            # API Key（加密存储）
├── .api_key_hash       # Key 哈希
├── usage.db            # 用量统计
└── logs/               # 日志文件
```

> ⚠️ 删除 `.moa-gateway` 目录会丢失所有配置和用量记录，请确认后再删。

## 7. 换电脑怎么迁移配置？

### 方法 1：复制配置文件

1. 在旧电脑上找到 `~/.moa-gateway/` 目录
2. 复制整个目录到 U 盘 / 云盘
3. 在新电脑上：
   - 先运行一次 `SuperMOA.exe`（会自动创建目录）
   - 关闭 SuperMOA
   - 将旧电脑的 `config.yaml` 覆盖到新电脑的 `~/.moa-gateway/` 目录

### 方法 2：手动重新配置

1. 在新电脑上运行 `SuperMOA.exe`
2. 打开配置页，选择推荐组合
3. 重新填入 API Key（API Key 不建议复制，建议在各厂商官网重新获取）

> 💡 API Key 加密绑定用户账户，跨电脑复制可能无法解密。建议重新生成：右键托盘 → 重新生成 Key，或运行 `SuperMOA.exe --regenerate-key`。

## 8. 多人能用同一个 SuperMOA 吗？

### 默认情况下：仅本机使用

SuperMOA 默认只监听 `127.0.0.1`，即只有本机的程序可以连接。

### 如果需要多人共享

理论上可以将监听地址改为 `0.0.0.0` 让局域网内其他人连接，但**不推荐**：

- ⚠️ 网络暴露风险增加
- ⚠️ 需要自行处理 HTTPS、防火墙等问题
- ⚠️ 多人共用一个 API Key 会导致用量混淆

> 📌 SuperMOA 的设计初衷是**个人本地使用**，不建议作为共享服务部署。

## 10. 数据安全吗？

**安全。SuperMOA 在数据安全方面做了全面设计。**

### 安全措施一览

| 方面 | 措施 |
|------|------|
| 🖥️ 本地运行 | 所有数据在本地处理，不上传任何用户数据 |
| 🔐 Key 加密 | API Key 使用 Windows DPAPI 加密存储，绑定用户账户 |
| 🔒 本地监听 | 默认只监听 127.0.0.1，不对外暴露 |
| 🚫 无遥测 | 无埋点、无追踪、无行为分析 |
| 📊 本地统计 | 用量数据存在本地 SQLite，不联网上报 |
| 📝 日志本地 | 调用日志仅存本地，自动轮转清理 |
| 🔑 独立 Key | SuperMOA 有自己的访问 Key（sk-moa-xxx），与上游 API Key 分离 |

### 数据流向

```
你的输入 → SuperMOA（本地）→ AI 模型 API（厂商服务器）→ 回答 → SuperMOA → 你
```

- SuperMOA **本身不运营任何中间服务器**
- 你的对话内容只发往你配置的 AI 模型厂商
- SuperMOA 不截留、不存储、不上传你的对话内容
