# 🚀 SuperMOA 快速上手指南

> 5 分钟，从零到能用。

---

## 第 1 步：下载 SuperMOA

1. 前往 [SuperMOA 发布页](https://github.com/SuperMOA/SuperMOA/releases)，下载最新版 `SuperMOA.exe`
2. 将文件保存到任意目录（如桌面）

> ⚠️ **如果浏览器提示"此文件可能有害"** — 这是浏览器对 .exe 文件的常规提示，点击「保留」即可。

### ✅ 预期看到

下载完成，`SuperMOA.exe` 文件出现在你保存的目录中。

---

## 第 2 步：双击运行

1. **双击** `SuperMOA.exe`
2. 如果出现 **Windows SmartScreen** 提示：
   - 点击「**更多信息**」
   - 点击「**仍要运行**」
   - 详见 [FAQ - Windows SmartScreen 拦截](faq.md#2-windows-smartscreen-拦截怎么办)
3. 如果杀毒软件报毒：
   - 这是 PyInstaller 打包的常见误报
   - 将 `SuperMOA.exe` 加入白名单即可
   - 详见 [FAQ - 杀毒软件报毒](faq.md#1-杀毒软件报毒怎么办)

### ✅ 预期看到

系统托盘（右下角）出现一个 **蓝色 S 图标** 🟦，说明 SuperMOA 已成功启动。

> 💡 如果没看到图标，可能被折叠了 —— 点击托盘区的「^」箭头展开即可看到。

---

## 第 3 步：打开配置页

1. **右键** 点击托盘区的蓝色 S 图标
2. 选择「**打开配置页**」
3. 浏览器会自动打开 `http://127.0.0.1:12345/`

> 💡 如果浏览器没自动打开，手动在浏览器地址栏输入 `http://127.0.0.1:12345/`

### ✅ 预期看到

浏览器打开配置页面，页面顶部显示你的 API Key（格式：`sk-moa-xxxx`），以及参考模型、聚合模型等配置区域。

---

## 第 4 步：选择推荐组合

1. 在配置页找到「**推荐组合**」区域
2. 选择一个适合你的组合：

| 组合 | 适合谁 | 单次成本 |
|------|--------|---------|
| 💰 性价比组合（推荐） | 大多数人日常使用 | ~¥0.02 |
| 💎 质量优先组合 | 需要高质量输出的场景 | ~¥0.08 |
| 🪙 极致省钱组合 | 预算紧张 | ~¥0.01 |

3. 点击选中后，配置会自动填充到各区域（但 API Key 还是空的）

### ✅ 预期看到

参考模型、聚合模型、透传模型的 URL 和模型名已自动填好，但 **API Key** 栏是空的，等待你填写。

---

## 第 5 步：填写 API Key

根据你选择的组合，去对应厂商官网申请 API Key，然后填入配置页：

### 各厂商 API Key 申请地址

| 厂商 | 申请地址 | 价格参考 |
|------|----------|---------|
| DeepSeek | https://platform.deepseek.com/ | 输入 ¥1/百万 token 起 |
| 阿里通义千问 | https://dashscope.aliyun.com/ | 输入 ¥0.5/百万 token 起 |
| 智谱 GLM | https://open.bigmodel.cn/ | 输入 ¥1/百万 token 起 |
| 腾讯混元 | https://cloud.tencent.com/product/hunyuan | 输入 ¥2/百万 token 起 |
| 字节豆包 | https://www.volcengine.com/ | 输入 ¥0.8/百万 token 起 |

> 💡 大部分厂商都有新用户免费额度，可以先体验。

1. 复制你申请到的 API Key
2. 粘贴到配置页对应的 **API Key** 输入框中
3. 参考模型、聚合模型、透传模型的 Key 都要填
4. 点击页面底部的「**保存**」按钮

### ✅ 预期看到

保存成功提示，配置页显示的模型状态变为可用（绿色 ✅）。

---

## 第 6 步：测试连接

1. 在配置页找到每个模型旁的 **⚡ 测试** 按钮
2. 逐个点击测试
3. 确认所有模型都显示「连接成功」

### ✅ 预期看到

所有模型旁的测试按钮显示绿色「✅ 成功」。

> ❌ 如果某个模型测试失败，请检查：
> - API Key 是否正确（没有多余空格）
> - base_url 是否正确
> - 你的厂商账户是否有余额/额度

---

## 第 7 步：开始使用！

现在 SuperMOA 已经准备好了。在你的 AI 智能体中配置：

| 设置项 | 值 |
|--------|-----|
| **Base URL** | `http://127.0.0.1:12345/v1` |
| **API Key** | 配置页顶部显示的 `sk-moa-xxxx` |
| **Model** | `SuperMOA` |

### 触发词速查

| 你想要的效果 | 怎么输入 |
|-------------|---------|
| 快速回答（省 Token） | 直接问，不加触发词 |
| 多模型聚合（最聪明） | 消息开头加 `hh：` |
| 直接调某个模型 | 消息开头加对应触发词，如 `hy3：` |

### ✅ 预期看到

你的智能体回复正常，且回复内容比单个模型更全面（使用 `hh：` 触发词时）。

---

## 🎉 完成！

恭喜，你已经成功配置并使用 SuperMOA 了！

## 常见问题

### Q: 配置页打不开怎么办？

1. 确认托盘图标还在运行（右键 → 启动服务）
2. 手动在浏览器输入 `http://127.0.0.1:12345/`
3. 检查端口是否被占用（换一个端口重启）

### Q: 测试连接失败怎么办？

- 检查 API Key 是否正确
- 检查厂商账户余额是否充足
- 检查网络是否能访问对应的 API 地址

### Q: 智能体连不上怎么办？

- 确认 Base URL 是 `http://127.0.0.1:12345/v1`（注意末尾 `/v1`）
- 确认 API Key 是 `sk-moa-xxxx` 格式
- 确认 Model 填的是 `SuperMOA`（大小写不敏感）
